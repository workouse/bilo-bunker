# Archived planning documents

These files are kept for history only. They describe earlier phases of the
project and **do not reflect the current architecture**.

| File | What it was |
|---|---|
| `tasks.md` | Original bootstrap roadmap for the Cloudflare Workers / KV / Durable Objects version. |
| `refactor.md` | Spec for the Cloudflare → self-hosted Docker refactor (proposed nginx + certbot; Caddy was adopted instead). |
| `refactor.task.md` | Step-by-step checklist for that refactor (completed; boxes were never ticked). |

For the current state see [`README.md`](../../README.md), [`DEPLOY.md`](../../DEPLOY.md)
and [`agents.md`](../../agents.md). Planned work is tracked in
[GitHub Issues](https://github.com/workouse/bilo-bunker/issues).
